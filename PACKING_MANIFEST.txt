四、新电脑还原步骤（摘要，详见项目 README.md / docs/目录与运行说明.md）
  1. 解压到不含空格与特殊字符的路径；用 7-Zip / WinRAR / Win10+ 自带解压，
     若中文目录名乱码，请在解压工具中指定文件名编码为 UTF-8。
  2. 核对本清单第五节的 SHA-256 或比对文件数。
  3. python --version 确认 >= 3.10；python -m pip install -r plum-platform/requirements.txt
  4. cd plum-platform 后执行 python start.py --reset（首次重建 data/plum.db 与基准数据）。
     Windows 可直接双击 start.bat。服务默认 0.0.0.0:8080。
  5. 浏览器打开 /health、/、/consumer、/biz、/admin、/visitor、/merchant 巡检。
  6. python tests/smoke_test.py（45 项）、node tests/mp_weixin_smoke.js（23 项）。
  7. 微信开发者工具「导入项目」选择 mp-weixin/；默认 mock 可独立跑通；
     切 local 需先启动服务并在详情→本地设置勾选「不校验合法域名」。
  8. 答辩材料直接打开 3 个 docx/pptx；如需重新生成，先装可选依赖，再依次执行
     _build/gen_figures.py → build_report.py → build_evaluation.py → build_slides.py
     → qa_slides.py → final_check.py。
