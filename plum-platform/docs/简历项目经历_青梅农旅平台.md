**项目名称**：大邑䢺江镇青梅产业农商文旅综合平台（全栈项目）

**项目简介**：面向乡镇青梅产业的农商文旅一体化平台。一个 Python 服务同时对外提供数据接口、游客 H5、商户 H5 工作台、PC 管理后台，并附带可导入微信开发者工具的游客小程序工程；各端业务数据统一落在同一 SQLite 库，默认零外部依赖、断网可演示。

**技术栈**：Python 3.10+ · Flask 3.0.3 · SQLite（21 张业务表）· 原生 HTML / CSS / JavaScript（前端无 Node 构建）· 微信小程序原生框架 · 可选扩展 PyMySQL + MySQL、外部大模型（OpenAI 兼容接口）

**核心功能 / 个人职责**：
- 后端以四组 Blueprint 组织接口（`/api`、`/api/merchant`、`/api/admin`、`/api/ai`），配套统一响应、会话鉴权、分页、幂等与操作日志等公共能力；订单 / 预约 / 审核 / 上下架共用一套状态机（非法状态迁移返回 409）。【待补充：本人具体负责的 Blueprint 或模块】
- 打通采摘预约与核销、农特商城下单支付发货、研学报名、民宿预订等业务流程，三类业务共用 `CK` 开头核销码，商户端一个入口统一核销。
- 实现本地 AI 四项能力：知识库客服、产品与活动文案、智能行程规划、语音讲解稿，均读取业务库实时数据；另设计"事实与措辞分离"的可选外部大模型扩展，含配置脱敏、失败回退与 MySQL 会话降级。
- 编写并维护验收脚本：接口端到端测试、三端界面巡检、PC 桌面巡检与小程序离线验收。【待补充：本人是否为测试脚本作者】
- 输出配套文档：开发任务书、目录与运行说明，以及毕业设计说明书、答辩 PPT 等交付材料。【待补充：本人执笔部分】
- 微信小程序含首页 / 列表 / 详情 / 我的 / 登录 5 个页面与 3 个 tabBar，内置 mock 模拟服务端，不启动后端即可独立跑通全流程。

**项目亮点 / 成果**（以下数字均来自本仓库 README 明示的当前验收结果）：
- 规模化验收：接口端到端 **45 项全部通过**、小程序离线 **23 项全部通过**、AI 扩展离线 **56 项**、PC 桌面巡检 **22 个场景全部干净**、三端界面巡检 **8 个场景全部干净**。
- 三端 + 小程序数据同源、登录态按命名空间隔离，同一浏览器可同时登录消费者 / 商户 / 管理员且互不顶号。
- 零外部依赖交付：无需配置密钥、无需 Node 构建、断网可跑；`python start.py` 或 Windows 双击 `start.bat` 一键启动。
